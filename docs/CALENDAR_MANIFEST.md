# Calendar manifest: classic (v1) and reference (v2)

Generated by `tools/calendar_manifest.py` from `golfsim/schedule.py`. 1463 series in v1, 1463 in v2, matched by stable series id (the qualifying waves were named by week in v1 and by wave in v2: `schedule.ALIASES` maps one onto the other). Weeks are the 52-week game season; days are the days of that week the event occupies. New worlds use v2; a world saved before calendar versions keeps v1 for good (no migration has been made or approved).

| Majors spacing enforced | no | 5 weeks |
| Day-level travel between events in one week | no (non-overlapping days only) | yes: none within a country, one free day within a region, two between regions |
